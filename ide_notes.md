# VS Code и Git: заметки

1. Удобно видеть список изменённых файлов и открывать diff.
2. Удобно просматривать историю и быстро переключать ветки.
3. Удобно разрешать конфликты через встроенный редактор.

В терминале удобнее выполнять повторяющиеся команды, интерактивный rebase и
сложные сценарии, которые требуют полного контроля над Git.
