# Git и SVN: сравнение

1. В Git ветка — это лёгкая ссылка на коммит, поэтому создание ветки почти не
требует времени и места. В SVN ветвление исторически связано с копированием
каталогов на сервере, поэтому операция тяжелее и сильнее зависит от сети.

2. Полноценный коммит в SVN без связи с сервером обычно невозможен: SVN —
централизованная система, и коммит записывается в центральный репозиторий.
В Git коммит создаётся локально и может быть отправлен позже.

3. SVN может быть предпочтительнее в старых корпоративных проектах, где уже
есть большая инфраструктура, регламенты, интеграции и команда сопровождения.
Также SVN иногда выбирают за централизованный контроль доступа и простую модель
для проектов с большими бинарными файлами.
